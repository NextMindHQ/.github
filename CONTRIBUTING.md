# Contributing

This repository (`NextMindHQ/.github`) controls the organization's public GitHub profile and, as it grows, the default community health files for the NextMind organization. It is not a product codebase — there's nothing to build or run here.

## Scope of this repo

- `profile/README.md` — the organization profile page.
- `PROFILE_PLAN.md` — the rationale and roadmap behind the profile.
- `assets/` — design specs and source files for profile media (banner, avatar).

## Changes to the profile

Changes to `profile/README.md` or brand assets should stay consistent with the direction in `PROFILE_PLAN.md` — dark, minimal, no marketing language. If you're proposing a change, open a pull request and explain the reasoning; small wording or copy fixes don't need extensive process.

## Org-wide contribution guidelines

NextMind doesn't yet have public product repositories, so there are no code contribution guidelines to publish here yet. Once a NextMind repository is opened to external contributors, this file will be expanded with the actual workflow (branching, review, testing expectations) and applied org-wide as the default `CONTRIBUTING.md`.
